# Project Guidance (OpenCode / AGENTS.md)

## Overview
Personal profile / portfolio page for Nikhil Sunchu. The `README.md` is
auto-generated from the SVG assets in `assets/` and the cached data in
`tools/profile/data/`.

## Repository structure
- `README.md` — rendered profile page (auto-regenerated by CI)
- `assets/` — generated SVGs (header, links, stats, cards, footer, stack)
- `assets/links/` — social link icons
- `tools/profile/` — Python generator for SVGs and README
  - `fetch.py` — fetches GitHub stats
  - `render.py` — renders SVGs
  - `readme.py` — writes `README.md`
  - `data/*.json` — cached stats (stats.json, calendar.json)
  - `icons.json` — icon mapping
- `.github/workflows/update-profile.yml` — daily cron (12:17 ET) that re-renders
  the profile and commits changes to `main`

## How to regenerate locally
Requires Python 3.12 and the packages pinned in the CI workflow:

    pip install fonttools==4.62.1 brotli==1.2.0

Then run:

    python tools/profile/fetch.py
    python tools/profile/render.py
    python tools/profile/readme.py

Committed outputs: `assets/`, `README.md`, `tools/profile/data/`

## CI
`.github/workflows/update-profile.yml` runs on a daily schedule, on
`workflow_dispatch`, and on pushes to `main` that touch
`tools/profile/*.py`, `tools/profile/icons.json`, or the workflow itself.
It uses `PROFILE_TOKEN` and `GITHUB_TOKEN` secrets (optional; `GITHUB_TOKEN`
is provided automatically by GitHub Actions).

## Notes
- No package manager, no build/lint commands. Test suite at `tools/profile/tests/`.
- `.gitignore` ignores `__pycache__/`, `*.pyc`, `.env`.
